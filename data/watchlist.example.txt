# 监视清单示例

# 复制本文件为同目录下的 watchlist.txt 使用（其不会被 git 跟踪）
# 注意：以 # 开头的行会被忽略

# 每行格式为 `<clusterId> | <商品名> | <预期价> | <收藏>`，可以只写 clusterId
# 后三段都能省：没设预期价就不用写第三段，没收藏就不用写第四段
# 收藏那一段固定写一个 *（收藏了就写，没收藏整段不写）
# 下面几种写法程序都能识别，但程序写回时会统一成上面那种格式（分享链接中 share_medium、bbid 等参数会被忽略）：
#   https://mall.bilibili.com/neul-next/resell/detail.html?clusterId=10000004212&noTitleBar=1&share_medium=android&bbid=XU8FF57870E1B13BBF6891E69F6F952B320E5
#   10000004212 | Vsinger 洛天依拍立得相框 规格：D款
#   10000004212 | Vsinger 洛天依拍立得相框 规格：D款 | 60
#   10000004212 | Vsinger 洛天依拍立得相框 规格：D款 | 60 | *
#   10000008780

# 预期价也可以双击表格「预期价格」单元格设置，只需填写数字，显示时会自动加上 ￥
# 收藏也可以单击表格最左边的「收藏」列切换（点一下亮起实心星，再点一下熄灭）
